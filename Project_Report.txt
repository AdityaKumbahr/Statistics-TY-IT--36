1. Introduction

Smartphones are available in a wide range of price segments, and their prices are associated with differences in memory, storage, processor performance, display characteristics, cameras, battery capacity and charging capability. RAM is one of the most visible specifications used to distinguish smartphone configurations. However, RAM is only one of many factors associated with the final price of a device.

This project uses statistical analysis and supervised machine learning to study smartphone pricing. The main focus is the relationship between RAM capacity and price, followed by a Multiple Linear Regression model that incorporates additional numerical specifications. The project follows a data-analysis workflow consisting of data understanding, preprocessing, exploratory data analysis, model training, prediction and evaluation.

2. Problem Statement

To statistically analyze the relationship between smartphone RAM capacity and smartphone price, and to develop a supervised Multiple Linear Regression model that predicts smartphone price using RAM and other available numerical specifications.

3. Objectives

Check the dataset for missing values and duplicate records.

Identify potential price outliers using the Interquartile Range (IQR) method.

Calculate descriptive statistics for important numerical variables such as RAM, storage and price.

Explore the relationship between RAM capacity and smartphone price using statistical measures and visualizations.

Analyze correlations among numerical smartphone specifications.

Build a RAM-only linear regression model to examine how much price variation can be explained by RAM alone.

Build a Multiple Linear Regression model using RAM and additional numerical smartphone specifications.

Evaluate the models using R², Adjusted R², Mean Absolute Error (MAE) and Root Mean Squared Error (RMSE).

Interpret regression coefficients while recognizing that statistical association does not establish causation.

The dataset contains RAM configurations from 2 GB to 24 GB. The most common configuration in the dataset is 8 GB, with 328 smartphones. Other frequently represented configurations include 12 GB (147 smartphones) and 4 GB (136 smartphones).

The Pearson correlation calculated in the notebook between ram_gb and price_inr is 0.5480. Among the numerical variables examined, clock speed and storage show stronger positive correlations with price than RAM. This supports the use of Multiple Linear Regression rather than relying on RAM as the only predictor.

After removing the five rows with missing values in the selected predictors, 753 observations remained. The data was divided using an 80:20 train/test split with random_state=42. This produced 602 training observations and 151 testing observations.
9.3 Multiple Linear Regression
A LinearRegression model from scikit-learn was fitted using the 11 selected predictors. The model was trained on the training set and used to predict prices for the unseen test set.
10. Model Evaluation

The R² value of 0.6724 indicates that approximately 67.24% of the variation in test-set smartphone prices is explained by the linear combination of the selected predictors in this model. The Adjusted R² is 0.6465 after accounting for the number of predictors. The MAE of ₹10,069.18 means that the average absolute prediction error on the test set is about ₹10,069. The RMSE of ₹16,856.03 gives greater weight to larger errors and is therefore higher than the MAE.
11. Interpretation of Regression Coefficients
The coefficients below represent the fitted association between each predictor and price while holding the other predictors in the model constant. They should not be interpreted as causal effects because the dataset is observational and the predictors are themselves correlated.

For RAM specifically, the fitted multiple regression coefficient is approximately ₹637.05. Under the ceteris paribus interpretation of the fitted linear model, a one-unit increase in RAM (1 GB) is associated with an estimated ₹637 increase in price while the other included predictors are held constant. This is a model-based association, not proof that adding exactly 1 GB of RAM would cause a phone's retail price to increase by ₹637.
The model intercept is approximately -₹245,481.79. The intercept is the predicted price when all model predictors are zero, a combination that is outside the realistic range of smartphone specifications. Therefore, the intercept has limited practical interpretation in this context.

12. RAM-Only vs Multiple Linear Regression

The RAM-only model has an R² of 0.2474, so RAM alone explains substantially less of the variation in smartphone prices than the combined model. Its MAE and RMSE are also higher. The multiple regression model therefore captures additional price variation by incorporating other smartphone specifications.
The RAM-only model has a coefficient of approximately ₹5,960.95 per GB. This coefficient is different from the ₹637.05 coefficient in the multiple regression because the latter estimates RAM's partial association after accounting for the other selected predictors. The difference illustrates why a single-variable relationship and a multivariable regression coefficient should not be interpreted as the same quantity.

14. Limitations
•	The notebook does not document the original public URL or publisher of smartphones.csv, so the external dataset provenance cannot be independently established from the project file alone.
•	The analysis is observational and therefore does not establish causal relationships between specifications and price.
•	The regression model uses only selected numerical features. Categorical variables such as brand, processor name, processor brand and operating system were not included in the model.
•	Potential multicollinearity exists because several smartphone specifications are correlated with one another. For example, RAM is correlated with rating and clock speed, while storage is strongly correlated with price.
•	The IQR method flags 80 price observations as outliers, but the notebook does not perform a sensitivity analysis with and without those observations.
•	The model is linear, so it may not fully capture nonlinear relationships or interactions among smartphone specifications.
•	The dataset represents the products contained in the source file and should not automatically be treated as a complete representation of the entire smartphone market.

15. Conclusion
This project examined smartphone pricing using statistical analysis and supervised learning. The exploratory analysis found a moderate positive correlation of 0.5480 between RAM capacity and price, and average prices generally increased across the major RAM categories represented in the dataset. However, the RAM-only regression model achieved an R² of only 0.2474, showing that RAM by itself does not explain most of the variation in smartphone prices.
The Multiple Linear Regression model, which incorporated RAM together with storage, rating, processor-related, display, battery, charging and camera features, achieved an R² of 0.6724 and an Adjusted R² of 0.6465. Its MAE was ₹10,069.18 and RMSE was ₹16,856.03 on the test set. The improvement over the RAM-only model demonstrates the importance of considering multiple smartphone specifications when analyzing or predicting price.
Overall, the project supports the statistical observation that higher-RAM smartphones tend to be associated with higher prices in the analyzed dataset, while also showing that smartphone pricing is a multivariable problem. The results should be interpreted as statistical associations within the dataset rather than as causal effects.
